# Nuna Photo Studio

Sitio web de Nuna Photo Studio: fotografía de retratos, eventos y alquiler de estudio en Santo Domingo.

## Contenido

- `index.html`: el sitio completo (Inicio, Servicios, Portafolio, Planes, Sobre nosotros, Contacto y Términos y condiciones). Las páginas se cambian dentro del mismo archivo.
- `assets/`: logos originales.
- `fotos/`: fotos del portafolio, optimizadas para web (máx. 1600 px).

## Ver el sitio

Abre `index.html` en el navegador, o publícalo gratis con GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Editar

- **Planes y precios:** busca `var PLANS` en `index.html`.
- **Portafolio:** busca `var WORKS`. Cada trabajo tiene categoría, título, foto (`src`) y tamaño (`""`, `"w"`, `"t"` o `"xl"`).
- **Redes sociales:** busca `var SOCIAL`.
